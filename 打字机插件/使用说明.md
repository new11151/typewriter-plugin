# 打字机插件 Typewriter — 使用说明

## 这是什么
把「已复制的文字」逐字自动打到光标位置，像真人输入法一样。启动后**后台静默运行**，无需打开任何软件界面，在任何能输入文字的地方（Word、记事本、网页、聊天软件）都能用。

## 完整插件包含
```
打字机插件/
├── 启动打字机.bat      ← 双击这个启动
├── Typewriter.ahk      ← 核心脚本
└── AutoHotkey/
    └── AutoHotkey64.exe ← 运行时（已内置，无需安装）
```
AutoHotkey 运行时已打包在内，**无需额外下载或安装任何东西**。

## 使用方法
### 自动模式（推荐）
1. **双击 `启动打字机.bat`** 启动插件（右下角托盘出现键盘图标）。
2. 按 **Ctrl+Alt+D** 开启"打字机模式"（屏幕会提示已开启）。
3. 在任意地方 **Ctrl+C 复制** 文字。
4. 切到目标窗口（如 Word），点好光标位置，按 **Ctrl+V**，倒计时 3 秒后逐字打出（而不是一次性粘贴）。
5. 不想用了，再按一次 **Ctrl+Alt+D** 关闭，Ctrl+V 立即恢复成普通粘贴。

### 手动模式
不开打字机模式时，也可随时按 **Ctrl+Alt+T** 读取剪贴板逐字打出。

## 快捷键
| 快捷键 | 功能 |
|--------|------|
| **Ctrl+Alt+D** | **打字机模式开关（开启/关闭 Ctrl+V 逐字打字）** |
| Ctrl+Alt+T | 手动开始打字（读取剪贴板） |
| Ctrl+Alt+P | 暂停 / 继续 |
| Ctrl+Alt+S | 停止 |
| Ctrl+Alt++ | 加速（间隔 -10ms） |
| Ctrl+Alt+- | 减速（间隔 +10ms） |
| Ctrl+Alt+Q | 退出插件 |
| **按任意键** | **打字中按键盘任意键即可立即停止** |

> 开启/关闭打字机模式时屏幕都会有提示；托盘双击也会显示当前模式状态。

## 开机自启
把 `启动打字机.bat` 的快捷方式放进启动文件夹即可：
按 `Win+R` → 输入 `shell:startup` → 回车 → 把快捷方式拖进去。

## 常见问题
- **按快捷键没反应？** 确认托盘里有键盘图标（插件在运行）；若被安全软件拦截热键，加白名单即可。
- **中文打不出？** 脚本用 `{Text}` 模式发送，理论上支持所有中文。若个别软件异常，尝试切到英文输入法状态再触发。
- **太快/太慢？** 打字中随时按 Ctrl+Alt++ / Ctrl+Alt+- 实时调速。默认间隔 80 毫秒/字。
